# 📖 Sobre o projeto

O **Synapse** é uma plataforma de produtividade desenvolvida para tornar estudos, tarefas e metas mais organizados e agradáveis visualmente.

A ideia do projeto é criar uma experiência moderna, dinâmica e confortável para o uso diário, fugindo daquela aparência genérica de plataformas tradicionais.

---

# 🎯 Objetivo

O Synapse foi criado com o objetivo de ajudar usuários a:

- manter consistência nos estudos;
- organizar tarefas e metas;
- melhorar produtividade;
- acompanhar evolução diária;
- reduzir distrações;
- criar uma rotina mais eficiente.
